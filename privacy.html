プライバシーポリシー（shachiku-youtube-uploader）

制定日：2026年10月15日

1. このツールについて

shachiku-youtube-uploader（以下「本ツール」）は、運営者が自分で制作した動画を、運営者自身のYouTubeチャンネル（@shachiku_wanko）へアップロードするための個人用ツールです。運営者以外の利用者はいません。

2. 取得する情報

本ツールは、Googleの認可（OAuth）により、運営者自身のYouTubeアカウントについて次の権限を使います。

  • 動画のアップロード（youtube.upload）
  • チャンネル情報の表示（youtube.readonly。アップロード先のチャンネルを確かめるため）

認可で得たトークンは運営者のパソコン内にだけ保存し、外部へ送ったり第三者と共有したりしません。

3. 利用目的

運営者の動画を運営者のチャンネルに投稿するためだけに使います。広告、分析、販売などには使いません。

4. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 権限の取り消し

Googleアカウントのサードパーティアクセスからいつでも取り消せます。

6. お問い合わせ

YouTube または X の @shachiku_wanko までご連絡ください。
